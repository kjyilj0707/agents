# 에이전트 연구실 (agent-lab)

Claude Code 에이전트들이 일하는 모습을 한 화면에 보여 주는 공용 도구다. 프로젝트마다 다른 것은 그 프로젝트의 `.lab/map.json` 하나뿐이다.

## 파일

| 파일 | 하는 일 |
|---|---|
| `hook.py` | Claude Code 훅. 이벤트마다 누가·무엇을·어느 파일을 했는지 `<프로젝트>/.lab/live/events.jsonl`에 한 줄 붙인다 |
| `server.py` | `127.0.0.1:<포트>`에서 화면·지도·기록만 내보내는 작은 서버 |
| `index.html` | 화면 (외부 CDN 없음, 순수 HTML/CSS/JS, 다크 테마) |
| `labctl` | 서버 켜기·끄기. 각 프로젝트의 `labmap`이 이것을 부른다 |
| `clawd/` | 캐릭터 SVG (저장소에 없음, `scripts/fetch-clawd.sh`로 가져온다) |

## 화면 (위에서 아래로)

1. **상단 바**: 프로젝트 이름, LIVE(초록 실시간 · 노랑 다시 보기 · 빨강 서버 꺼짐), 일하는 에이전트 수, 도구 호출 수, 세션 선택, 시연 재생, 화면 비우기, 범례
2. **에이전트 줄**: 캐릭터 카드. 쉼·읽음·씀·실행·맡김·오류·끝에 따라 그림이 바뀐다. 총괄 → 담당 위임은 조직도 선이 빛나며 점이 흐르고, 끝나면 점이 총괄로 돌아온다(보고). 지도에 없는 에이전트는 회색 카드로 저절로 생긴다
3. **코드·데이터 흐름**: 단계별 상자와 화살표. 에이전트가 파일을 만지면 카드에서 상자로 점이 날아간다(파랑 읽기 · 주황 쓰기 · 초록 실행). 여러 에이전트가 만지면 "공유 n". 🔒 민감, "보호" 보호 경로, 점선 외부 서비스
4. **타임라인**: 멈춤 · 처음부터 · 1/2/4/8배속 · LIVE 복귀, 막대를 누르면 그 시점부터 다시 보기
5. **활동 기록**: "총괄이 백엔드에게 일을 맡김", "백엔드가 state.ts 수정" 같은 쉬운 문장

기록이 없으면 **시연 재생**이 지도만 보고 가짜 흐름(약 35초)을 만든다.

## 기록 규칙 (hook.py)

- 남는 것: 시각, 이벤트 종류, 세션 앞 8자, 에이전트 이름, 도구 이름, 읽기/쓰기/실행 구분, 프로젝트 기준 파일 경로(최대 12개), Bash에 Claude가 붙인 짧은 설명, 위임 대상, 외부 서비스 종류(notion·drive·github·slack·figma·web).
- 남지 않는 것: 사용자 메시지, 도구 결과, 파일 내용, Bash 명령 원문, 위임 지시문 본문, `.env` 경로.
- 5MB를 넘으면 `events_날짜.jsonl`로 넘기고 새로 시작한다.
- 어느 프로젝트인지는 `CLAUDE_PROJECT_DIR`(없으면 cwd)에서 위로 올라가며 `.lab/map.json`을 찾아 정한다.
- 메인 세션 이벤트에 에이전트 이름이 없으면 지도의 `main_agent`로 기록한다.

## 지도 `.lab/map.json`

예시는 [`../templates/project/.lab/map.json`](../templates/project/.lab/map.json).

| 키 | 뜻 |
|---|---|
| `project` | 화면 제목 |
| `main_agent` | 메인 세션 에이전트 id (예: `team-chief`) |
| `port` | 서버 포트. 프로젝트마다 겹치지 않게 |
| `agents` | `id`, `name`, `role`, `color`(hex), `readonly`(선택) |
| `stages` | 단계 → `nodes`(`id`, `label`, `paths`: 프로젝트 기준 경로 앞부분, `sensitive`/`protected`/`external` 선택). 한 파일이 여러 노드에 걸리면 가장 긴 경로가 이긴다 |
| `flows` | `[노드id, 노드id]` 화살표 |
| `externals` | 외부 서비스 → 노드 id. `notion:read`/`notion:write`처럼 읽기·쓰기를 나눌 수 있다 |
| `outside` | (선택) 프로젝트 밖 폴더 별칭. `{"@tools": "~/tools"}`이면 `~/tools/a.py`를 `@tools/a.py`로 기록한다. 여러 프로젝트를 위에서 관리하는 "관제탑" 폴더용 |

## 실행

```bash
./labmap          # 서버 켜고 브라우저로 열기
./labmap up       # 서버만
./labmap stop
./labmap status
```

## 보안

- 서버는 `127.0.0.1`에만 열린다. Host 머리글이 `127.0.0.1`/`localhost`가 아니면 403.
- 내보내는 것은 공용 폴더의 정적 파일, 그 프로젝트의 `.lab/map.json`, `.lab/live/events.jsonl`뿐이다. `/../`, `%2e%2e` 같은 경로 탈출은 404.
